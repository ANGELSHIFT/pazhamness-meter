## ✨ key Features

- **💨 Retro Arcade & Pixel Art Aesthetic**:
  - 16-bit realistic pixel banana with authentic Kerala curvature, ripeness spots, and clean transparent edges.
  - Classic NES / Mario HUD (`1UP: 02540`, `★ INSERT PAZHAM ★`, `HIGH: 99990`) rendered in `Press Start 2P` font.
  - Custom Web Audio API procedural square-wave sound synthesizer (coin blips, level fanfares, jump whooshes, judge gavels).

- **�🌌 Minion Bob Upload Zone**:
  - Cheering Minion Bob featuring the iconic dialogue: *OPOWER... GLORY... BANANAAAAAA!*.
  - Drag-and-drop or click-to-upload photo scanner.

- **👀 Infinite Dancing Banana Borders**:
  - 4 continuous vertical streaming lanes of dancing bananas running along the screen borders.

- **p��� 8-Page Multi-Stage Results Carousel**:
  - **Verdict**: Overall Ripeness Score (0-100) & Status.
  - **Life Line**: Super Mario World style 5-level journey (`LVL 1: VAZHA` to `GAME OVER: RIP`).
  - **Amma Approval**: Concurrence meter with authentic Kerala mother reactions.
  - **Pazham Passport**: Official citizenship card stamped with state seals.
  - **Pazham Court Trial**: Manglish prosecution, defense, and judge sentence (compulsory Pazham Pori duty).
  - **Banana Personality**: Archetype profile card (e.g. *The Golden Child*).
  - **Scientific Report**: 4-part optical spectrum analysis (Yellowness, Spot Density, Stability, Survival).
  - **Destiny & Share**: Confetti celebration, printable summary, and retry buttons.

## 😡 Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/ANGELSHIFT/pazhamness-meter.git
cd pazhamness-meter

# 2. Install dependencies & build
npm run build

# 3. Start the application
npm start
```

Visit `http://localhost:5000` in your browser!
